# 📘 Student Performance Prediction using Machine Learning

## 📌 Project Overview
This project predicts students' final grades (G3) using machine learning techniques. 
The goal is to analyze academic and socio-behavioral factors that influence student performance.

## 🎯 Objective
To build regression and classification models that:
- Predict final grade (G3)
- Identify important influencing factors
- Compare performance with and without historical grades (G1, G2)


## 📊 Dataset Description
The dataset contains student academic records and behavioral attributes such as:
- Absences
- Failures
- Study time
- Health
- Going out frequency
- Age
- G1, G2 (previous grades)
- G3 (final grade)



## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn



## 🤖 Models Used
- Random Forest Regressor
- Random Forest Classifier



## 📈 Model Evaluation Metrics
- MAE (Mean Absolute Error)
- RMSE (Root Mean Squared Error)
- R² Score



## 🔍 Key Insights
- G1 and G2 strongly influence final grade prediction.
- Absences and prior failures negatively impact performance.
- Socio-behavioral factors alone have limited predictive power.



## 📌 Conclusion
Random Forest model effectively predicts student performance. 
Including historical grades significantly improves model accuracy.
